This repository contains hands-on DevSecOps practical exercises focused on Docker containerization and security practices. The labs demonstrate how to build, run, and secure containerized applications using Docker and related DevSecOps principles.

**Overview**

The labs within this repository demonstrate the integration of security at every stage of the Docker development workflow. This includes writing efficient Dockerfiles, orchestrating multi-container environments, and implementing security scanning to mitigate vulnerabilities.

**1. CI/CD Automation**

Focus: GitHub Actions integration.

Details: Implementation of automated workflows to build and push Docker images.

Key Tasks: Configuring build contexts, managing secrets, and optimizing workflow paths for efficient delivery.

**2. Docker Container Security** 

Focus: Hardening and Vulnerability Management.

Details: Deep dive into securing the container runtime and image layers.

Implementing "Least Privilege" principles (non-root users).

Reviewing security documentation for industry best practices.

**3. Lifecycle & DevSecOps Lab**

Focus: Manual vs. Automated workflows.

Details: Understanding the full Docker lifecycle (Create, buid, Run).

Key Tasks: Documenting the transition from manual container management to automated DevSecOps pipelines.

**4. Multi-Container Orchestration** 

Focus: Docker Compose.

Details: Managing complex environments with multiple interconnected services.

Key Tasks: Defining docker-compose.yml files, managing persistent volumes, and configuring internal bridge networks for secure service communication.
The practicals were completed as part of a learning journey DevSecOps.
The full structured documentation and extended learning materials are based on the reference repository: https://github.com/samuel-nartey/devops-labs
